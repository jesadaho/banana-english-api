BANANA ENGLISH — FOUNDATION A1 PATH (CONTENT-ONLY ROADMAP)
Version: 1.0

หลักการ
- ใช้ mechanic เดิมเท่านั้น: Lesson, Emoji Speak, Say It in English, Describe It, Explain It, Mission
- คง node/id และเนื้อหาของ Foundation เดิมที่ user เล่นอยู่ ห้ามสลับหรือลบ node เดิม
- บทใหม่ให้เป็น content addition และเปิด Coming soon จนกว่าจะมี script/test พร้อม
- ทุกบทจบด้วย personal หรือ real-use challenge ภายใน 5–6 turns
- Emoji Speak ใช้ทบทวนคำศัพท์ (noun/verb/adjective) เป็นหลัก; ประโยคให้ใช้ Say It in English
- Describe It/Explain It ใช้เฉพาะประโยคสั้นที่เรียนมาแล้ว ไม่เพิ่ม grammar ใหม่แบบก้าวกระโดด
